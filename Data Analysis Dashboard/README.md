# Data Analysis Dashboard

## Overview
This Task analyzes sales data and displays useful information using summary cards, charts, filters, and a table.

## Data

The dataset contains the following columns:

- **Product Name:** Name of the product sold.
- **Category:** Category to which the product belongs (e.g., Electronics, Furniture).
- **Quantity:** Number of units sold for the product.
- **Month:** Month in which the product was sold.
- **Revenue:** Total revenue generated from the product sale.

## Dashboard Summary
- Total Revenue: Displays the total revenue of all records.
- Average Revenue: Displays the average revenue.
- Highest Revenue Product: Shows the product with the highest revenue.
- Lowest Revenue Product: Shows the product with the lowest revenue.

## Filters
- **Category Filter:** Displays data for the selected product category.
- **Month Filter:** Displays data for the selected month.
- Both filters update the charts, and table dynamically.
- Both filters make dynamically if data change than value of filter change.

## Charts
- **Bar Chart:** Shows product-wise total revenue.
- **Line Chart:** Shows month-wise revenue trend.

## Table
The table displays all sales records including Product Name, Category, Month, and Revenue. It updates automatically when filters are applied.
